Correlation and Visualisation in R

In this guided Code Along, you’ll investigate the relationship between age and baseline severity in a synthetic healthcare dataset. You’ll prepare a focused analysis dataset, build an informative scatterplot, calculate and test Pearson’s correlation, and create a figure caption that updates directly from the statistical results.

🎯 You’ll learn to

  • Construct and interpret a scatterplot with ggplot2.
  • Add a fitted linear trend with geom_smooth().
  • Calculate Pearson’s correlation coefficient.
  • Run and interpret cor.test().
  • Extract estimates, confidence intervals, and p-values.
  • Create a dynamic statistical figure caption.

💡 Keep magnitude and evidence separate

A large sample can provide strong evidence that a weak correlation differs from zero. Always report and interpret the coefficient itself—not only its p-value—and do not treat a fitted line or correlation as evidence of causation.
